# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In addition, contributors must not:

- Add live exploits, credential stealers, or real command-and-control code
- Point the demo fetch target at infrastructure they do not operate
- Use this project against people or systems without authorization
- Strip the research notices from the README or `NOTICE` file

Violations may be reported via the repository’s security advisory channel.
